## 2.18.1 可视化跟随音乐、真实歌曲调参与稳定性

- 可视化闪烁跟随音乐：银河、星空、黑洞共用一个节拍检测，只认 150 Hz 以下的底鼓起音（以最低一格为主），门槛同时参考这首歌的典型鼓点和低频近期的起伏，不再被贝斯音符、人声和管弦乐的低频涌动频繁触发；换到更安静的歌后几秒内重新跟上鼓点；节拍闪在鼓点后约 0.1 秒内淡入到最亮、再渐渐暗下去，下一拍前基本回暗，不再常亮也不刺眼；星空的拖尾和光晕渐显，飞行速度带惯性，每颗星的亮度也平滑过渡。各频段和每颗星的亮度按这首歌自己的近期水平计算，响亮的母带也有明暗起伏，响的段落更亮、间奏更暗，开头不再一阵强光。银河星芒按强度挑选并从门槛渐显，不再按绘制顺序一帧换一个；星空和黑洞也加上与银河同款的十字星芒（同屏最多 10 个、8 个，银河 14 个），并沿用银河的配色规则：黑洞附近的星偏暖、外圈冰蓝白与主题色、外围点缀少量互补色宝石星，环绕粒子内暖外冷；星空以主题色为主（约 65%），点缀冰蓝白、暖色和约 2% 宝石星，拖尾与星同色；ECO 模式下星空不再单帧频闪；“动画速度”对三种模式的闪烁速度都生效。
- 真实歌曲调参：新增 `pnpm tune:visualizer`。`capture` 用 FFmpeg 解码本地歌曲，按 Web Audio 分析器（Blackman 窗、2048 点、-90…-10 dB）与应用的 256 格归一化还原可视化收到的频谱并保存（只存频谱，不存音频）；`report` 把采集回放给真实的节拍检测与三个场景，输出每首歌的节拍数、规律性、每拍亮暗起伏、单帧最大变亮（频闪）、开头亮度、亮度与响度相关性，并生成带时间线的 HTML 报告。采集与报告在不提交的 `tuning/` 目录。
- 稳定性：退出时不再报 “Object has been destroyed” 和 “write after end”（原生宿主输入流关闭时请求立即失败）；日志按 5 MB 轮转并保留两份旧日志；在线 PCM 诊断正常时每 30 秒记一行，出现丢包、背压、欠载等异常时立即记录；标题栏双击按收到消息时的状态切换，Windows 自行还原后不再被程序重新最大化；黑洞的冷暖分区按实际窗口尺寸计算，窄窗口不再错位。
- 工程：ESLint 清零；在线页与设置页按需加载，第三方库单独分包，主包由 943 kB 降到约 487 kB，格式解析器仍按需加载；可视化测试改为行为测试（对合成歌曲测量每帧亮度：起伏、频闪、段落、开头），能分别拦下 2.18.0 的“常亮”与改版初期的“频闪”；新增 `pnpm release`（见下文）。

## 2.16.1 视频 VST 状态查询超时修复

视频 PCM 宿主打开 VST 编辑器或更新机架时，会先完成正在进行的状态查询，再暂停 60 毫秒状态轮询，操作结束后恢复。避免较慢的插件命令让排队的 `status` 查询超过 5 秒并误判宿主无响应。原生宿主、音频协议和安装包未改变。

## 2.16.0 视频通道条与播放列表导航修复

视频音量面板沿用音乐通道条的插件槽、搜索入口、排序、旁路开关、插件编辑器及音量推子设计。视频 PCM 机架修改会实时同步到正在播放的原生宿主，失败时保留原机架。视频控制栏的“播放队列”重新进入播放列表，可从左侧“正在播放”返回视频。未制作安装包。

## 2.15.9 视频播放列表与音量独立面板

视频底部状态卡片拆分为播放列表和音量两个按钮：前者只显示当前文件与队列，后者只显示主输出推子和视频 PCM 机架插件。视频控制栏中的“播放队列”也打开同一队列面板。两个面板互斥，音量面板采用更窄的通道条布局，并按面板宽度为视频画面让位。音乐模式的队列与音量入口不变。

## 2.15.8 视频侧栏与主输出推子

视频播放时，右侧栏上方显示当前文件和播放队列，下方显示主输出推子与正在视频 PCM 机架中加载的插件。底部喇叭按钮和播放状态卡片都可打开该侧栏；音量推子沿用音乐模式的拖动、键盘、滚轮、双击归一及静音操作。点击已加载插件可打开其实时编辑界面。HDMI 编码直通时推子停用，视频音频仍由功放控制。

## 2.15.7 视频 VST 双声道 PCM 同步修复

视频 PCM 不再由 FFmpeg 的独立实时节奏驱动，而按原生宿主实际消耗量保持有界预缓冲；画面等到音频开始输出后再播放，并计入 VST 报告的处理延迟。缓冲可吸收短暂的主进程阻塞，避免原先反复断流、重新预缓冲造成的卡顿和音画漂移。HDMI 编码直通和普通视频播放链路不变。

Windows 桌面音乐播放器与音乐可视化工作站，使用 Electron、React、TypeScript、Web Audio 与 JUCE Native Host。

## 2.15.6 视频双声道 PCM → VST 机架原型

视频播放器增加可选的“视频 VST 机架 · 实验”模式。非编码直通视频仍由 mpv 显示画面；FFmpeg 将所选音轨解码成 48 kHz 双声道 PCM，送入现有 JUCE/VST 宿主与音乐输出设备。此模式不加载原有视频 DSP；编码直通继续由 mpv 独立输出并绕过机架。播放、暂停、定位、切音轨和音量变更会同时更新 PCM 流。开启前先配置音乐机架；实验模式默认关闭，可随时关闭以恢复原视频音频链路。实际音画同步和插件延迟仍需在目标设备试听验证。

## 2.15.5 扩展视频格式

导入文件、拖入、外部文件队列和主进程视频校验均识别 `.wmv`，以及 `.asf`、`.flv`、`.ogv`、`.3gp`、`.3g2`、`.f4v`、`.vob`、`.mxf`、`.rm`、`.rmvb`、`.mts`、`.m2t`、`.m1v`、`.m2v`、`.divx`、`.mpe`、`.m2p`、`.qt`、`.tp`、`.trp`、`.vro`、`.mpv`。使用已有 mpv 解码；WMV2 + WMA2 和各新增容器的本机生成样本已验证。具体文件仍取决于其中的编码、损坏情况和输出设备。

## 2.15.4 视频 PCM 输出声道与音效顺序

普通视频音频根据 mpv/WASAPI 实际 PCM 输出声道决定音效。输出为双声道时，音轨即使是单声道、5.1 等，先用 FFmpeg 布局转换为双声道，再应用视频音效；真实多声道 PCM 输出旁路。切换音轨/设备时先卸载旧滤镜并重新测量输出，编码直通始终旁路。

## 2.15.3 视频进度圆形滑块

仅本地视频进度条增加 14px 主题色圆形拖动指示，随播放和拖动预览移动。保留现有点击、拖动和键盘定位逻辑；音乐波形绘制不变。

## 2.15.2 强效果视频 DSP

替换原来的 M/S 比例算法：空间模拟使用左右不同的短延迟及三组早期反射；对白增强使用居中信号的 120–6000 Hz 频段、2.2 kHz 提升与并行压缩。两个效果可以叠加，不再互相抵消。
输出加入 0.92 峰值限制并补偿限幅延迟。直通完全不加载滤镜；非双声道走原样旁路，不生成中置音箱声道。
默认仍关闭；点“试听空间”或“试听对白”以 80% 开始比较，再调整强度。高强度会改变音色，不代表音质更保真。

普通原生音乐与 HDMI 一样，在当前音轨加载完成后才开始状态轮询。

不屏蔽已就绪设备的真实错误。修复准备阶段失败被误判为设备中断并触发后端降级的路径。
构建、状态边界回归、真实视频／音乐混合队列、快速切换及音乐电平恢复测试通过。

## 2.14.0 当前结构

- 本地音乐支持 Chromium Web Audio 或 JUCE Native/VST 输出。
- YouTube 与网易云固定使用 Web Direct，不进入 Native/VST 链路。
- YouTube 可视化仅分析当前网页播放器自身的媒体流，不监听 Windows 系统声音。
- 本地、在线和 Native 分析统一输出 256 个频谱点，并共用显示平滑、增益和频段范围。
- 支持深色、浅色、亚克力、云母、沉浸式、简易播放器和全透明显示。

## 构建与测试

```powershell
pnpm build
pnpm build:native
pnpm test
```

完整验证：

```powershell
pnpm verify
```

准备好 `ffmpeg/ffmpeg.exe` 后制作 Windows NSIS 安装包：

```powershell
pnpm release
```

`pnpm release`（`scripts/release.ps1`）在完整验证后打包，并自动处理两件事：找不到 pnpm 时依次尝试 corepack 和常见安装位置；源码路径含中文等非 ASCII 字符时临时用 `subst` 映射到空闲盘符再构建（CMake 在这类路径下会失败），结束后解除映射。已验证过、只想重新打包时加 `-SkipVerify`。等价的手动命令是 `pnpm dist:win`。

可视化真实歌曲调参：

```powershell
pnpm tune:visualizer capture D:\Music\某张专辑   # 也可以直接给文件
pnpm tune:visualizer report                       # 生成 tuning/report.html 与 report.json
```
