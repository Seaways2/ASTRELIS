# Auralis licence status

Status date: 2026-08-11

Auralis does not currently declare a project licence. No open-source or proprietary licence is granted by this file.

## Release gate

Public distribution of Auralis 2.3.5 is blocked until the project owner confirms, with appropriate legal advice if needed:

1. the licence under which Auralis itself is distributed;
2. the JUCE 8 licence route used by the project and the required developer seats;
3. compliance for the bundled FFmpeg executable and its exact GPL-enabled build;
4. required source offers, notices, attribution and EULA wording;
5. any future ASIO SDK licence and trademark obligations.

This file records an unresolved engineering/release decision. It is not legal advice and must not be presented as proof of licence compliance.
